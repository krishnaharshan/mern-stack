# MERN Stack Learning Repository

A personal web-development learning repository containing hands-on practice in **HTML, CSS, JavaScript, Tailwind CSS, React/Next.js, Node.js concepts, logging, and beginner projects**.

> This repository is primarily a learning workspace. Some folders are experiments, exercises, and unfinished examples rather than production-ready applications.

## 📚 What You'll Find

| Area | Contents |
| --- | --- |
| **HTML** | HTML fundamentals, tables, forms, semantic HTML, ARIA practice, and media examples |
| **CSS** | Selectors, box model, Flexbox, Grid, responsive layouts, navigation bars, Bootstrap, and landing pages |
| **JavaScript** | Fundamentals, data types, operators, arrays, loops, functions, OOP, prototypes, DOM, modules, promises, async/await, closures, and generators |
| **JavaScript Projects** | Todo app, weather app, e-commerce practice, expense tracker, quiz app, and weather dashboard |
| **Backend** | Node.js concepts, EventEmitter-based logging, file logging, and backend notes |
| **Tailwind CSS** | Tailwind experiments, responsive layouts, and Vite/React practice |
| **React / Next.js** | Starter projects using modern React and Next.js setups |

## 🚀 Getting Started

This repository contains multiple independent exercises, so there is **no single command that runs everything**.

### HTML / CSS / Vanilla JavaScript

Open the relevant `.html` file directly in a browser, or use a local development server such as the VS Code Live Server extension.

### Vite + React projects

For a Vite project, move into its project directory and run:

```bash
npm install
npm run dev
```

For example:

```bash
cd tailwinds/krish
npm install
npm run dev
```

### Next.js project

The Next.js project is located at `tailwind/tailnextfour`:

```bash
cd tailwind/tailnextfour
npm install
npm run dev
```

Then open the local URL shown by Next.js in your terminal.

## 🔒 GitHub Safety

Generated and machine-specific files are intentionally excluded from version control through `.gitignore`, including:

- `node_modules/`
- `.next/`
- build/cache directories
- environment files such as `.env`
- logs
- editor/OS files
- temporary VS Code runner files

The original workspace also contained a large `html/rolex.mp4` file. It is **not included in the GitHub-ready copy** because GitHub repositories have strict individual file-size limits. Keep large media in external storage or Git LFS if it is genuinely required by a project.
